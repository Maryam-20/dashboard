A modern admin dashboard. This project showcases a dashboard interface with a sidebar navigation, user profile section, project cards, announcements, and trending items.

## Features

- **Sidebar Navigation** - Clean left sidebar with organized menu items and sections
- **User Profile Section** - Header with search functionality and user information
- **Project Cards** - Grid layout displaying project cards with action buttons
- **Announcements** - Dedicated section for important updates and announcements
- **Trending Section** - Display of trending projects and users
- **Modern UI Design** - Clean design with smooth styling and color scheme


## Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Grid layout, flexbox
- **SVG Icons** - Lightweight vector icons from Material Design

## Layout Components

### Sidebar
- Logo with grid icon
- Primary navigation menu (Home, Profile, Message, History, Tasks, Communities)
- Secondary menu (Settings, Support, Privacy)

### Main Content
- **Header Section** - Search bar and user profile with notification icon
- **Welcome Section** - Personalized greeting with action buttons
- **Projects Grid** - Multiple project cards with star, eye, and fork interaction icons
- **Announcements Panel** - Important updates and news
- **Trending Section** - Popular users and projects

## Getting Started

1. Clone or download the project files
2. Open `index.html` in your web browser
